# Capture 画面の見た目

Capture の画面で使う色、書体、配置の正本。Week 3 の実装手順は [20-week3-capture-web.md](./20-week3-capture-web.md)。Week 4 以降の Capture 画面も、この文書のトークンと糸を使う。

## 画面の仕事

対象は、スマホで「いまの一文」を残し、自分の記録を時刻順に見返す人。

一日をカードの束にしない。時刻は左の一本の苔糸でつなぎ、各行はその糸の節になる。入力は画面下、親指の届く位置に固定する。濃い色は「記録する」「保存する」と節の点だけに使う。

```text
┌──────────────────────────┐
│  Hibi              アカウント │
│  10月18日 日                │  明朝。今日の日付（Asia/Tokyo）
├──────────────────────────┤
│  ● 14:02  牛乳を買う         │  左の糸と節。行全体が detail へ
│  │ 09:11  資料を送る         │
├──────────────────────────┤
│  ┌ 何を残しますか        ┐ │  葉色の面。safe-area を足す
│  └          記録する     ┘ │
└──────────────────────────┘
```

詳細は、同じ糸の上で一文を開き、保存と削除を分ける。

```text
10月18日 14:02
本文の編集欄
保存する
────────
削除する
```

## トークン

| 役割 | 値 | 使い所 |
| --- | --- | --- |
| Field | `#EEF3EF` | Capture layout の背景。クリーム地にはしない |
| Ink | `#15201A` | 本文 |
| Moss | `#1E6B43` | 記録する、保存する、時刻の節 |
| Leaf | `#F7FBF8` | 下段コンポーザの面 |
| Dusk | `#5A6A62` | 時刻、補助文 |
| Thread | `#D5E3D9` | 糸、区切り、入力枠 |

ログインとアカウントは、このトークンへ置換しない。Capture layout の中だけに使う。

## 活字

- 日付と Hibi: Shippori Mincho。日付だけを大きくし、本文には使わない
- 本文: Noto Sans JP、17px、行間 1.7
- ボタン: 既存のサンセリフ
- 時刻: tabular-nums

## 部品

- 一覧の背骨は苔の糸と節。行にカードの影を付けない
- コンポーザは画面下に浮かぶ葉色の面で、上方向にだけ薄い影を置く
- 空の一覧も糸の最初の節として出し、「最初の一文を書いてください」と書く
- 削除は保存ボタンから離し、確認は `window.confirm` のまま
- 番号、status バッジ、処理状態の色分けは付けない。処理中の見せ方は Week 4 で、この糸の上に足す

## コピー

- 送信: 「記録する」（送信中: 「記録しています」）
- 更新: 「保存する」（送信中: 「保存しています」）
- 削除: 「削除する」（送信中: 「削除しています」）
- 空一覧: 「最初の一文を書いてください」
- 422 の入力エラー: 入力欄の直下。API の `detail` を見出しにしない
