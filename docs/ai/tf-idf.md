# キーワード検索の TF-IDF

[Week 8 の検索](../architecture/26-week8-search.md) で、キーワード検索の順位に使う式です。意味検索のベクトル距離とは別です。

## 対象

点数を付ける前に、次の文書だけを候補にします。

- `user_id` が検索した人と同じ
- `status` が `completed`

この候補の件数を `N` とします。別ユーザーの行と、`pending`、`processing`、`failed` は `N` にも点数にも入れません。

## 語への分割

本文とクエリは、同じ規則で語のリストにします。空白では分かれ、ひらがな、カタカナ、漢字、数字の連続をそれぞれ 1 語にします。

| 文字列 | 語 |
| --- | --- |
| `牛乳を買う` | `牛乳`、`を`、`買`、`う` |
| `牛乳` | `牛乳` |
| `ミルク` | `ミルク` |
| `ランチ 1200 円` | `ランチ`、`1200`、`円` |
| `あとで読む記事` | `あとで`、`読`、`む`、`記事` |

## TF-IDF とは

TF-IDF は、クエリの語が文書にどれだけ当たるかを点数にする方法です。クエリの各語について TF と IDF を掛け、その和を文書の点数にします。点数が高い文書ほど、キーワード検索の上位になります。

## TF とは

TF（term frequency）は、ある語がその文書の中に現れる回数です。`牛乳を買う` の語は `牛乳`、`を`、`買`、`う` なので、この文書での `牛乳` の TF は 1 です。同じ語が 2 回出ていれば TF は 2 です。クエリに無い語は、その文書の点数には使いません。

## IDF とは

IDF（inverse document frequency）は、ある語が候補の中でどれだけ限られた文書に現れるかを表す重みです。候補のうち、その語を 1 回以上含む文書の件数を `df` とします。同じ文書に 2 回出ていても `df` は 1 です。含む文書が少ない語ほど IDF は大きく、その語が当たった文書の点数を押し上げます。候補のすべてに含まれる語の IDF は 1 になり、点数への寄与は TF と同じになります。

## 式

語 `t` について、候補のうち `t` を 1 回以上含む文書の件数を `df(t)` とします。

```text
tf(t, 文書) = その文書の中の t の出現回数
idf(t) = log((1 + N) / (1 + df(t))) + 1
score(文書) = クエリの各語についての tf × idf の和
```

`log` は自然対数です。最後の `+ 1` は、候補が 1 件だけのときにも一致した文書の点数が 0 にならないようにするためです。

スコアが 0 の文書は結果に入れません。残った文書はスコアの高い順です。同点なら `capture_id` の昇順です。

## 例

候補が次の 3 件だけだとします。

- `牛乳を買う`
- `あとで読む記事`
- `ランチ 1200 円`

クエリ `牛乳` の語は `牛乳` だけです。`N` は 3、`df(牛乳)` は 1 です。

```text
idf = log((1 + 3) / (1 + 1)) + 1 = log(2) + 1
tf(牛乳を買う) = 1
score(牛乳を買う) = log(2) + 1
```

`あとで読む記事` と `ランチ 1200 円` は `牛乳` を含まないので、スコアは 0 です。結果は `牛乳を買う` だけです。

クエリ `ミルク` は、3 件のどれにもその語がありません。結果は 0 件です。意味検索では `ミルク` が `牛乳を買う` に近くても、キーワード検索の点数には使いません。
